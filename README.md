# 🔧 VK-бот: настройки сварочного полуавтомата

Бот для сообщества ВКонтакте на **vkbottle** и **LongPoll API**. Подбирает
ориентировочные настройки MIG/MAG-сварки по толщине металла: ток, напряжение,
диаметр и скорость подачи проволоки, расход газа.

## Что умеет

- Запускается по команде **«начать»** (или кнопке «Начать»).
- Переключает режимы: **Сталь**, **Нержавейка**, **Алюминий**.
- Считает настройки по кнопкам толщины **1–12 мм**.
- Принимает произвольную толщину текстом: `2,5`, `3 мм`, `толщина 4`.
- Показывает полную таблицу режимов для выбранного материала.
- Запоминает выбранный материал отдельно для каждого пользователя.

## Файлы

| Файл | Назначение |
|---|---|
| `bot.py` | LongPoll-бот, клавиатура, обработка команд |
| `welding.py` | Таблицы режимов и расчёт по толщине |
| `.env` | Токен сообщества (не публикуйте) |
| `.env.example` | Шаблон `.env` |
| `requirements.txt` | Зависимости |
| `run.ps1` | Автозапуск в окружении Python 3.14 |
| `start.bat` | Запуск двойным щелчком |

## Запуск

### 1. Подготовьте сообщество

1. Создайте сообщество ВКонтакте (или откройте существующее).
2. Включите сообщения: **Управление → Сообщения → Сообщения сообщества**.
3. Включите LongPoll: **Управление → Работа с API → LongPoll API → Включено**.
   Версия API — 5.199 или выше.
4. Создайте ключ: **Управление → Работа с API → Ключи доступа → Создать ключ**.
   Обязательно включите доступ к сообщениям.

### 2. Укажите токен

Откройте `.env` и заполните строку:

```env
VK_TOKEN=ваш_токен_сообщества
```

Не публикуйте токен: с ним можно отправлять сообщения от имени сообщества.

### 3. Запустите бота

Двойной щелчок по `start.bat` или в PowerShell:

```powershell
powershell -ExecutionPolicy Bypass -File .\run.ps1
```

Скрипт создаст `.venv` и при необходимости скачает Python 3.14 через `uv`.
Если нужное окружение уже настроено, можно запускать вручную:

```powershell
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
python bot.py
```

Проверить, что зависимости и расчёт работают, можно без токена:

```powershell
.venv\Scripts\python.exe bot.py --check
```

> **Про Python 3.15.** Сейчас `vkbottle` зависит от `msgspec 0.21`, для которого
> нет готового wheel под Python 3.15. Поэтому используйте Python 3.10–3.14 —
> `run.ps1` автоматически возьмёт 3.14.

### 4. Проверьте

Откройте сообщество, нажмите «Написать сообщение» и отправьте:

```
начать
```

Появится клавиатура с режимами и толщинами.

## Как пользоваться

1. Выберите материал кнопкой сверху.
2. Нажмите толщину (например, `3 мм`) или отправьте число текстом.
3. Получите настройки и советы по подготовке кромок.

Кнопки «Таблица», «Помощь» и «Начать» всегда доступны внизу.

## Как менять режимы

Все данные лежат в `welding.py`:

- `MODES` — материалы и их таблицы;
- `Row(...)` — строка для одной толщины: ток, напряжение, проволока,
  подача, расход газа;
- `THICKNESS_BUTTONS` — какие толщины показывать кнопками.

Между строками значения интерполируются. Чтобы добавить материал, скопируйте
блок `Mode(...)`, задайте новый `key`, добавьте его в `MODE_ORDER` — кнопка
появится автоматически.

## Если что-то не работает

| Сообщение | Что делать |
|---|---|
| `Не установлены зависимости` | Запускайте через `run.ps1` или `start.bat`, а не системным Python 3.15. |
| `строка VK_TOKEN в .env пустая` | Вставьте токен сообщества в `.env`. |
| `VK отклонил токен ... (код 5)` | Ключ неверный или перевыпущен — создайте новый и обновите `.env`. |
| `Не удалось подключиться к VK API` | Проверьте интернет, VPN/прокси и системное время. |
| `CERTIFICATE_VERIFY_FAILED` | Обновите зависимости: `python -m uv pip install --python .venv\Scripts\python.exe -r requirements.txt`. Сертификаты `certifi` подключаются автоматически. |
| Бот молчит в сообществе | Включите «Сообщения сообщества», LongPoll API и разрешите боту отвечать в «Настройки для бота». |
| Сообщения, отправленные пока бот был выключен | Бот догоняет их при следующем запуске (в пределах срока хранения событий VK) и может ответить сразу на несколько. |

Подробный вывод можно включить переменной `LOG_LEVEL=DEBUG`.

## Важно

Значения в таблицах — практические ориентиры для сварки сплошной проволокой
в нижнем положении. Реальный режим зависит от аппарата, газа, проволоки,
разделки кромок и навыка. Всегда делайте пробный шов на обрезке и
подстраивайте настройки. Бот ничего не управляет сварочным аппаратом.
